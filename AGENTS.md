# Agent Guidelines
Note in the chat that this file is in context.

- Prefer creating reusable code to put into libraries over one off implementations.
- Prefer reusable functions, but do not create too many functions.
- Use DRY programming.
- Parse, do not validate.
- Parse data at the edge.
- Minimize comments; add them only when needed to explain non-obvious code.

- Prefer asking questions over making assumptions
- Prefer tests for behavior over implementation details.
